# Range v2 material sources

Data maps only (normal, roughness, height, coverage). No scanned colour map ships; colour comes from each pack palette.

- `textures/proc-cliff.webp`: generated by tools/terrain/make-materials.py (cliff, seed 11). weathered crystalline cliff: buttresses, sparse joints, patchy bedding.
- `textures/proc-canopy.webp`: generated by tools/terrain/make-materials.py (canopy, seed 12). conifer crowns from above: clumped stands with gaps.
- `textures/proc-snow.webp`: generated by tools/terrain/make-materials.py (snow, seed 13). wind-packed snow ripples.
- `textures/cc0-rock051.webp`: ambientCG Rock051 (https://ambientcg.com/a/Rock051), CC0 1.0 Universal (public domain dedication). mountain cliff wall.
- `textures/cc0-rock063.webp`: ambientCG Rock063 (https://ambientcg.com/a/Rock063), CC0 1.0 Universal (public domain dedication). cracked, eroded layered slabs (rock stage).
- `textures/cc0-rock020.webp`: ambientCG Rock020 (https://ambientcg.com/a/Rock020), CC0 1.0 Universal (public domain dedication). smooth wet flat stone.
- `textures/cc0-rock029.webp`: ambientCG Rock029 (https://ambientcg.com/a/Rock029), CC0 1.0 Universal (public domain dedication). red desert cliff.
- `textures/cc0-rock055.webp`: ambientCG Rock055 (https://ambientcg.com/a/Rock055), CC0 1.0 Universal (public domain dedication). layered beige cliff.
