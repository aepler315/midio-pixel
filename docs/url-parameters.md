# URL parameters

> Generated by `node tools/settings-reference.mjs` from
> `src/config/settingsRegistry.js`. Do not edit by hand; `npm test` fails
> when this file is stale. Architecture: [settings](settings.md).

Every parameter below is an optional override of a registered setting.
Precedence is **URL → saved preference → default**. A URL value applies to
the visit and is shown in Settings with a *From page address* badge; it is
not saved unless you choose **Save as my settings**. An invalid value is
rejected and reported in Settings → Diagnostics (some parameters keep a
historical fallback, noted below). Unknown parameters are ignored and listed
in Diagnostics. **Copy share link** builds a URL with only the settings that
differ from their defaults.

Lifecycle: when a change reaches a running page.

- **Live** (`live`): Immediately.
- **Next landscape** (`next-landscape`): From the next landscape or replay.
- **Next song** (`next-song`): When the next song starts.
- **Scene rebuild** (`scene`): Rebuilds the scene in place; the song holds its place and resumes when the scene is ready.
- **Renderer restart** (`renderer`): Restarts the 3D landscape renderer; the song holds its place and resumes when the new scene is ready.
- **Reload** (`reload`): Needs a page reload, which stops playback.

- `maxQuality` — The most detail automatic quality may use. It still sheds detail below this to keep playback smooth.
- `fpsCap` — 60 draws every frame; 30 skips every other frame and halves GPU work. URL rule: `30` or `60`.
- `perf` — Where automatic quality starts each song. Automatic starts phones and small screens one step down. Lite starts two steps down; Full starts at full detail.
- `rangeRenderer` — 3D terrain uses WebGL2 scenery and falls back to the painted ranges on its own when it cannot run. Painted always uses the lighter 2D ranges. Inactive unless: The Teton highway tour always uses 3D terrain.
- `fps` — An on-screen frames-per-second counter. The P key toggles it too. URL rule: the bare parameter (any value except `0`/`off`) shows the counter.

## Retired or ignored parameters

Accepted without error, reported as ignored in Diagnostics.

- `style` — The Classic/Rendered style switch was retired; one look remains.
- `rangePipeline` — The single-stage pipeline was removed with the Pixel and Palette looks; Cinematic always uses the hybrid composite.
- `experience` — Every song plays in Landscape.
- `rangeExperience` — Every song plays in Landscape.
- `pixelScale` — Pixel scaling is Uniform; the option was removed.
- `seed` — Seeds are not read from the URL; tools pin them through the page.
- `fpsHud` — Use fps=1.
- `version` — Read by the version-history shell (src/ui/HistoryPicker.js), not the app.
