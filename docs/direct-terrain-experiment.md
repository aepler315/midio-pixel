# Terrain-only pixel experiment

Add `?directTerrain=1` to the app URL to try the Alpine Landscape direct renderer. The normal renderer remains the default. The experiment composes the sky, water, weather, light, and screen effects at output resolution, with terrain partitions sampled onto the selected output-aligned grid at their original depth boundaries.

This is a work in progress. Palette and cinematic reconstruction happen per terrain layer, so the resulting colors can differ from applying them to a finished scene. During scene arrival and under memory pressure, some water or cast may fall back to the pixel grid. The skyline is the same one-pixel ink line and clip edge as the normal renderer, read from the same probe; interior ridges and shorelines draw no line. The sky is painted back above the line after the near partition, so sky-side light added between partitions is lost in those few rows, and a live line can be a frame or more old (there is no grid to align it to). Captures use the finished display frame; a larger export upscales that frame, line included, and can soften terrain cells rather than re-rendering effects at export resolution. Integer scaling is not yet reproduced exactly. Effects and terrain appearance, mobile performance and memory use have not been reviewed on a real device.
