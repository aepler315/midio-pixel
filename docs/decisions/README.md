# Engineering decisions

Start at [0001: verification paths and reconnaissance](0001-agent-verification.md).

For a consequential choice, add `NNNN-short-name.md`: date/status, problem,
choice, evidence, alternatives, tradeoffs and consequences. Link source or PR.
A later decision can supersede an earlier one by linking both. Keep ordinary
implementation details in code and PRs. Do not turn aspirations into implemented
behavior or historical review holds into permanent product restrictions.
